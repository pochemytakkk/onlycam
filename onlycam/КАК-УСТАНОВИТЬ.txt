OnlyCam — телефон как веб-камера в Windows
==========================================

После установки в списке камер (OBS, Discord, Zoom, Teams) появляется
устройство "OnlyCam". OBS Studio больше не нужен.


ШАГ 1. Скачать приложение
-------------------------
1. Открой репозиторий на GitHub -> вкладка Actions.
2. Слева выбери "Build Windows app", открой последний зелёный запуск.
3. Внизу, в разделе Artifacts, скачай "OnlyCam-Setup" и распакуй архив.


ШАГ 2. Установить
-----------------
1. Запусти OnlyCam-Setup.exe (Windows попросит права администратора —
   они нужны, чтобы зарегистрировать виртуальную камеру).
2. После установки откроется приложение OnlyCam.
3. Если в приложении написано "Виртуальная камера не зарегистрирована",
   нажми кнопку "Установить виртуальную камеру".


ШАГ 3. Подключить телефон
-------------------------
Вариант А. Через браузер (ничего ставить на телефон не нужно)

1. Телефон и компьютер должны быть в одной Wi-Fi-сети.
2. В приложении выбери "Телефон через браузер (QR-код)".
3. Нажми "Запустить камеру" — появится QR-код.
4. Наведи камеру телефона на QR-код и открой ссылку.
5. Браузер скажет, что сертификат не доверенный. Это нормально: сертификат
   создаётся на твоём компьютере, соединение не выходит за пределы Wi-Fi.
   Safari: "Подробнее" -> "Посетить этот веб-сайт".
   Chrome: "Дополнительные" -> "Перейти на сайт".
6. Разреши доступ к камере и нажми "Стримить".
7. Не сворачивай вкладку — iOS выключает камеру в фоне.

Вариант Б. Через приложение OnlyCam на iPhone

1. Собери IPA: Actions -> "Build iPhone IPA" -> Run workflow, затем скачай
   артефакт "OnlyCam".
2. Поставь IPA на iPhone через Sideloadly (нужен Apple ID; бесплатная подпись
   живёт 7 дней, потом переустановить).
   - Установи Apple Devices (или iTunes) и iCloud с сайта Apple.
   - Подключи iPhone кабелем, разреши "Доверять компьютеру".
   - На iPhone: Настройки -> Основные -> VPN и управление устройством ->
     доверять своему профилю разработчика.
3. Открой приложение на iPhone — оно покажет адрес вида
   http://192.168.0.10:8080/stream
4. В Windows-приложении выбери "Приложение OnlyCam на iPhone", впиши этот адрес
   и нажми "Запустить камеру".


ШАГ 4. Включить камеру в программах
-----------------------------------
OBS:      Источники -> "+" -> "Устройство захвата видео" -> Устройство: OnlyCam
Discord:  Настройки -> Голос и видео -> Камера: OnlyCam
Zoom:     Настройки -> Видео -> Камера: OnlyCam

Если OnlyCam не появился — закрой программу полностью (Discord из трея тоже)
и открой заново: список камер читается при запуске.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
- Телефон не открывает страницу: проверь, что оба устройства в одной сети и
  что брандмауэр Windows разрешил OnlyCam доступ к частной сети.
- Чёрный кадр в OBS: в приложении OnlyCam должно быть видно превью и надпись
  о подключённом телефоне; если превью пустое — источник не подключён.
- Камеры нет в списке: нажми "Установить виртуальную камеру" и согласись на
  запрос администратора.
